Project

Build a complete Shopify Online Store 2.0 theme for Rafríkið (rafrikid.is / rafríkið.is), an Icelandic electrical supplies retailer based in Þorlákshöfn. The store sells lighting, wiring accessories, distribution board equipment, cable, industrial automation components, EV charging, solar, and HVAC — sourced from European wholesale distributors.

The store serves two audiences at once:

Fagaðilar (trade — electricians, contractors, facility managers) who buy by MPN/EAN, care about stock, lead times, box quantities and net prices excluding VAT.
Neytendur (consumers) who buy one light switch, want a picture, a plain-language description, and a price with VAT already in it.

The theme must serve both without feeling like two bolted-together sites. This is the central design problem — solve it with a single VAT display mode toggle and progressive disclosure of technical data, not with separate storefronts.

Fork Shopify's Dawn theme as the base. Do not build Liquid from scratch. Dawn gives working AJAX cart, predictive search, section rendering API, and accessibility scaffolding. Restyle it heavily and add the custom sections described below.

Hard constraints — read before writing code

These are real Shopify platform limits. Do not design around features that don't exist.

A theme controls price display, not price calculation. Genuine trade net pricing (customer-specific price lists) requires Shopify Plus B2B or a wholesale app. Build the theme so it reads a trade price from a variant metafield custom.verd_fagadili if present and falls back to the standard price if not. Document this clearly.
Customer tags are the segmentation mechanism. A logged-in customer tagged fagadili is trade. Everyone else is a consumer. Read tags in Liquid via customer.tags contains 'fagadili'.
Icelandic VAT is 24% on electrical goods. Shopify stores are configured with tax-inclusive pricing in Iceland, so product.price includes VAT. Excluding-VAT display = price | divided_by: 1.24. Round to whole krónur. Never let the two figures disagree by rounding drift — compute the excl figure from the incl figure, always, in one snippet.
ISK has no decimal subunit in practice. Format as 12.450 kr. — period as thousands separator, space before kr., no aura. Build one snippets/verd.liquid and use it everywhere; do not scatter money formatting.
Shopify's native search does not reliably index metafields. If MPN and EAN live in metafields, they will not be findable. Mirror MPN and EAN into product tags on import so predictive search finds them, and note this requirement in the README.
Do not use <form>-free hacks or client-side price overrides that would let a customer manipulate what they pay. Display only.
Visual direction

Do not produce a generic e-commerce theme. The identity comes from the trade's own materials.

Signature element: the PE stripe. IEC 60446 protective-earth conductor colouring — green with a yellow stripe — is instantly recognisable to every electrician in Iceland and reads as a confident graphic device to everyone else. Use it as a diagonal-striped 4px rule that marks section boundaries, the active nav item, and the top edge of the header. It appears exactly there and nowhere else. It is the one bold move; everything else stays quiet.

Typography — load from Google Fonts, all three support Icelandic þ ð æ ö á í ó ú ý:

Display: Archivo, weight 700–800, tight tracking. Headlines, section titles, price figures.
Body: Public Sans, 400/600. Descriptions, navigation, everything conversational.
Data: IBM Plex Mono, 400. MPN, EAN, SKU, box quantities, technical specs. Monospace here is functional — it makes part numbers scannable and visually separates machine data from human copy. This distinction is the theme's core dual-audience device: consumers ignore the mono text, trade buyers read only the mono text.

Layout: dense but not cramped. 1280px max content width. Product grid 2 columns mobile / 4 desktop. Generous vertical rhythm on marketing surfaces, tight tabular rhythm on data surfaces. Border radius 2px throughout — near-square, not pill-shaped.

Motion: minimal. Hover state on product cards raises elevation and reveals the technical data line. Cart drawer slides. Nothing else animates. Respect prefers-reduced-motion.

The VAT toggle — the most important component

A persistent control in the header, visible on every page:

Verð:  [ Með vsk ]  [ Án vsk ]

Behaviour:

Stores choice in localStorage under key rafrikid_vsk.
Defaults to Með vsk for anonymous visitors and untagged customers.
Defaults to Án vsk for customers tagged fagadili.
Switching re-renders every price on the page without a reload.
The non-active figure is always shown as a small secondary line beneath the primary price, in --rf-stal, so neither audience ever has to do mental arithmetic: 3.980 kr. án vsk / 4.935 kr. með vsk.
Persists across pages, is read in Liquid on first paint where possible to avoid a flash of the wrong price.

Label the toggle exactly: Með vsk and Án vsk. Header hint text: Sýna verð.

Quality floor
Fully responsive from 360px. Mobile is the trade user standing in a van.
Lighthouse: performance ≥ 90 mobile, accessibility ≥ 95.
Keyboard navigable with visible focus rings in --rf-kopar. Skip link. Correct heading hierarchy. All interactive elements have accessible names in Icelandic.
lang="is" on <html>. Icelandic characters must render correctly everywhere including in the mono face — test with Þórður æfði ýkt góða sólóið á öllum þökunum.
Images lazy-loaded with correct sizes, WebP via Shopify's image_url filter.
No external JS beyond Shopify's own and the optional SheetJS on the hraðpöntun page.
Product structured data (JSON-LD) with priceCurrency: "ISK".
Do not build

Flag these in the README as out of scope for the theme, requiring apps or Shopify configuration:

Customer-specific price lists and volume discounts (Plus B2B or wholesale app)
Invoice / 30-day payment terms (Plus B2B, or manual draft orders)
ERP or supplier stock feed sync
Icelandic payment providers (Teya, Rapyd, Netgíró, Pei, Aur) — configured in Shopify Payments settings, not the theme
Automatic kennitala lookup against fyrirtaekjaskra
